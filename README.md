# AeroCrash Sandbox

A browser-based aircraft crash-physics sandbox built with Three.js.

## Play
Open the GitHub Pages URL for this repository:
*https://phillycheese704.github.io/aerocrash-sandbox/*

## Controls

### Keyboard
- W / S — dive / climb
- A / D — turn
- Shift — throttle up
- Space — throttle down; brakes at idle near/on the ground
- C — camera
- N — airport navigation
- T — advance local time
- R — restart scenario
- Esc — menu

### Controller (standard Gamepad API)
- Left stick — steer / pitch
- RT / R2 — throttle up
- LT / L2 — throttle down / brake
- A / Cross — camera (or skip replay)
- X / Square — airport navigation
- Y / Triangle — advance time
- Start / Options — menu
- Back / Share — restart

### Mobile
Landscape mode is recommended. Use the on-screen stick and throttle/camera/navigation controls.

## Hosting
This is a static site. GitHub Pages can serve it directly from the repository root.

Three.js is loaded from jsDelivr, so an internet connection is required.
